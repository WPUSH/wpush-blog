WPush 的产品文档一直放在主站的[文档中心](https://wpush.cn/docs/)，回答的是「接口怎么调」。但用户更常问的是另一类问题：服务器告警怎么进微信、定时任务跑完怎么通知、AI Agent 干完活怎么叫我。这类问题需要更完整的上下文和更多的例子，于是有了这个博客。

## 栏目

- **接入教程**：每个渠道从绑定到收到第一条消息的完整步骤，配可直接运行的请求示例。
- **解决方案**：按场景组织，比如服务器告警、定时任务、AI Agent 通知、用户触达。每篇都给出可落地的脚本或配置。
- **文章**：产品更新、实践心得，以及我们对消息推送的一些思考。

## 给 AI 工具的版本

每篇文章都提供纯 Markdown 版本，在文章头部点「Markdown 版本」即可，地址是在网页地址后加 `.md`。站点根目录下的 `llms.txt` 列出了全部文章的 Markdown 地址，`llms-full.txt` 是全文合集，方便 Claude、Cursor 等工具直接读取。
